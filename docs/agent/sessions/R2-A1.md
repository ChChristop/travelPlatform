## Changes
1. **Replaced `checkOwnership` logic**: The previous implementation only checked if `PlanVersion.projectId` was truthy (non-empty), which is a tautology for valid entities and never catches real mismatches. The new implementation performs a cross-entity check:
   - Iterates over `CostRecord`s where `subject.type === 'planItem'`.
   - Looks up the referenced `PlanItem`.
   - Looks up the `PlanItem`'s `PlanVersion`.
   - Compares `CostRecord.projectId` against `PlanVersion.projectId`.
   - If they differ, it pushes an `ownership-mismatch` error citing the `CostRecord` id, the `PlanItem` id, and both project IDs.
2. **Removed exploratory comments**: Deleted all "Let's assume...", "Actually, the task says...", and other reasoning-trail comments from the file.
3. **Updated `validateReferenceRules`**: Passed `costRecords` to `checkOwnership` to enable the new logic. No changes to `ReferenceEntities` interface were needed as it already contained the required fields.
